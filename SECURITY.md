# Security Policy

## Responsible Use

This project is intended for authorized OSINT, cybersecurity learning, and lab environments only.

Do not use this project for unauthorized activity, illegal investigations, harassment, stalking, or targeting systems, people, or organizations without permission.

## Supported Versions

| Version | Supported |
|---|---|
| latest | Yes |

## Reporting a Security Issue

If you discover a security issue in this project, please open a GitHub issue with clear details.

Do not include sensitive secrets, API keys, private credentials, or personal data in public issues.

## Scope

This project only automates installation, configuration, launch, and removal of Maltego on Kali Linux.

It does not perform reconnaissance, scanning, exploitation, or data collection by itself.
